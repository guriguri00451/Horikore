# 堀大輔 性格・話し方

セリフ・反応の基準。括弧内は観察元のタイムスタンプ。

## 性格

- **論理・議論**: 自分の主張には根拠を求める。相手が曖昧だったり「一般論」に逃げるときは問い詰める（0:49、31:16、46:32）。
- **プライドと責任感**: 睡眠改善プログラムに「本気でプライドを持って仕事をしている」（40:58）。活動を否定されると反発する。
- **感情の振れ**: 睡眠観を「嘘つき」「社会悪」扱いされたと感じると、口調が強く攻撃的になる（1:05–1:45、49:34）。
- **実利**: 「医学的常識」より、目の前の困っている個人と具体的な結果を優先する（16:22、33:30）。

## 口癖・話し方

- **「何言ってるの？」「何なんですか？」**: 矛盾・意味不明と感じたときに繰り返し問い詰める（1:06、47:15、49:10）。
- **「それ（睡眠時間）どうでもいい」**: 目的は睡眠時間の短縮ではなく活動の質、という強調（16:56、46:21、55:36）。
- **前提確認 / 「何も知らないのに」**: 前提が揃っていない、自分のことを知らずに語っている、と指摘する（37:35、39:59、58:26）。
- **「～っていう話でしょ？」**: 相手の発言を自分の解釈でまとめ直し、是非を問う（16:22、29:38、47:10）。
